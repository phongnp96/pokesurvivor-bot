## 📥 Hướng dẫn cài đặt chi tiết trên mọi thiết bị

### 🖥️ Cách 1: Cài đặt trên Máy tính (Chrome, Cốc Cốc, Edge, Brave...)
1. Nhấn nút xanh **`Code`** ở đầu trang này ➔ Chọn **`Download ZIP`** (hoặc tải file `pokesurvivor-extension-v1.0.0.zip` trong repo).
2. Giải nén file zip. Bạn sẽ thấy thư mục con tên là `extension`.
3. Mở trình duyệt, truy cập đường dẫn sau:
   * Chrome / Cốc Cốc / Brave: `chrome://extensions`
   * Microsoft Edge: `edge://extensions`
4. Bật công tắc **Developer mode (Chế độ dành cho nhà phát triển)** ở góc trên bên phải.
5. Nhấn nút **Load unpacked (Tải tiện ích đã giải nén)** ➔ Chọn thư mục `extension`.
6. Truy cập vào game [pokesurvivor.com](https://pokesurvivor.com) hoặc [pokesurvivor.doofcraft.com](https://pokesurvivor.doofcraft.com) ➔ Menu bot sẽ tự động xuất hiện!

### 🤖 Cách 2: Cài đặt trên Điện thoại Android (Dùng Kiwi Browser)
1. Cài đặt trình duyệt **Kiwi Browser** miễn phí từ Google Play Store (Kiwi hỗ trợ cài Extension máy tính trên Android).
2. Tải file ZIP của extension về điện thoại và giải nén.
3. Mở Kiwi Browser ➔ Nhấn vào dấu **3 chấm `⋮`** ở góc trên bên phải ➔ Chọn **Tiện ích mở rộng (Extensions)**.
4. Bật **Chế độ dành cho nhà phát triển (Developer mode)**.
5. Nhấn nút **`+ (from .zip / .crx / dir)`** ➔ Tìm chọn thư mục `extension` (hoặc file zip của extension).
6. Mở trang web [pokesurvivor.com](https://pokesurvivor.com) hoặc [pokesurvivor.doofcraft.com](https://pokesurvivor.doofcraft.com) và xoay ngang màn hình để trải nghiệm.
